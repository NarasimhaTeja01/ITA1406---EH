# AI-Driven IoT Device Security and Attack Prevention System

This repository contains the Capstone Implementation for the AI-Driven IoT Device Security and Attack Prevention System.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
